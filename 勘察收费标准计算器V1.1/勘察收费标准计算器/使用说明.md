# 工程勘察收费标准计算器（2002）· 使用说明

**版本 v1.1 by DK星爷**

依据：国家计委、建设部《工程勘察设计收费标准》（2002 年修订本），计价格〔2002〕10 号。
单机运行，不联网、不写注册表，所有数据保存在本机。

---

## 一、界面结构

界面分三栏，与预算模板的编制习惯一致：

| 区域 | 作用 |
|---|---|
| 左栏 | 五个计价模块：**工程勘察、室内试验、工程物探、其他费用、工程测量**；下方为**各费用占比饼图**（按基准价构成，含图例百分比）与**费用汇总**（各分部实物费/技术费/小计、基准价、下浮、合同价、**折合综合单价**） |
| 中栏 | 当前模块的录入表单（工程测量按**地面 / 水域 / 管线 / 洞室 / 其他**五个横向标签分页）；模块底部为该模块的**分部统计**（实物工作费 / 技术工作费 / 分部小计 / 技术费比例 / 计入基准价）与逐条计算明细 |
| 右栏 | 对应章节的收费标准原表（表 2.2-1 ~ 表 8.4-3、总则 1.0.13），可切换页签对照；工程测量页签会先列**复杂程度判定表**再列基价表 |

顶栏：工程名称、建设单位、勘察等级（甲/乙/丙，决定岩土工程技术工作费 120%/100%/80%）、
帮助、打开、保存、**导出 Excel**、**生成报告**。

## 二、工程勘察模块（工作量录入 + 取费）

模块顶部有两个切换：

- **人工录入** / **导入理正备份库** —— 两种模式各自保留一套数据，来回切换互不覆盖：
  - 人工录入：标准地层带**层底深与柱状图**，钻孔按「孔型 + 数量 + 孔深」自定，适合预算阶段。
  - 导入理正备份库：「选择理正备份库」按钮选文件后直接取实测数据；标准地层**不显示层底深**（深度以实测分层为准），
    钻孔布置的**孔深按备份库实测值只读、不可修改**。
- **计价类别：预算 / 结算** —— 决定报告标题与口径说明（导入理正后自动切到结算）

### 2.1 标准地层

| 列 | 说明 |
|---|---|
| 主层号 - 亚层号 | **两格都填数字**，与理正标准层口径一致（主层编号 TCZCBH + 亚层编号 TCYCBH）：左格填主层编号 `1`、`2`、`3`…（新增地层自动延续，增删后自动重排；手工改过主层号后不再自动重排），右格填亚层编号 `1`、`2`…（可空，用于同一主层再细分：夹层、透镜体、溶洞）。界面层号显示为 `1`、`1-1`、`6-1`，**导出 Word / Excel 时自动转成报告惯用的圈码**：`①`、`①1`、`⑥1` |
| 岩土名称 | **点输入框即弹出「标准岩土名称」面板**（两列完整列出全部预设，不再被浏览器原生下拉截断），点一条即填入并自动带出岩土类别；也支持直接键入自定义名称。预设 18 项：素填土、杂填土、淤泥、淤泥质填土、黏土、粉质粘土、红黏土、粉土、粉砂、细沙、中沙、粗砂、圆砾、泥岩、砂岩、硅质岩、花岗岩、石灰岩 |
| 岩土类别 | 选名称后**自动按标准带出** Ⅰ~Ⅵ，仍可手工改（同名土层的稠度、密实度、风化程度不同可能跨类） |
| 层底深 / 层厚 | **仅人工录入模式**显示。层底深度自上而下递增，层厚自动计算；钻孔穿过地层时按层底深度自动截断并拆分深度档。**最后一层的层底深留空即可**（框内显示 `∞ 至孔底`）——按**无穷**处理，自动延伸至各孔孔底，不必填写；如确实要限定末层层底，直接填数字即可 |

右侧同步显示地层柱状图（人工录入模式），颜色按岩土类别区分。
导入模式下标准地层只有**主层号 / 亚层号 / 岩土名称 / 岩土类别 / 分层记录**几列——每层的层底与层厚以各钻孔实测分层为准。
亚层号只影响层号显示与标注，不改变分层计价（计价仍按每层的岩土类别与层底深度）；报告与 Excel 分层明细中的层号统一按圈码输出。旧版本项目里的 `①`、`①1` 层号在打开时自动迁移成 `1`、`1-1`。

**标准地层改一次，其他项目自动跟着改**（无需重新录入）：

| 修改标准地层的… | 自动同步到 |
|---|---|
| 岩土名称 | 标贯 / 动探行的「试验土层」、理正导入的钻孔分层名称 |
| 岩土类别 | 标贯 / 动探行的类别（单价随之重算）、钻孔分层类别 |
| 层底深度 | 标贯 / 动探的试验深度档（仅当该行档位还是按旧深度自动带出的，手工改过的不动）；孔内实测层底不变 |
| 删除某层 | 引用该层的标贯 / 动探记录一并移除，并提示移除条数；孔内实测分层保留 |

标贯 / 动探行按「第几层」记录引用，所以即使两层同名（例如理正库里的 ②红黏土、③红黏土），
改其中一层也不会影响另一层；只有早期版本保存的、没有层序信息的老项目才按名称匹配。

### 2.2 钻孔布置

- **人工录入模式**：钻孔总数 → 点「按一半分配」即得控制孔（默认一半）、鉴别孔（其余）。
  每种孔型可单独设数量与孔深；「+ 增加孔型」可再加其他孔型（如取土孔、波速孔）。
- **导入理正模式**：直接列出备份库里的全部钻孔（孔号 / 孔型 / 孔深 / 分层），
  **孔深为实测值、只读不可修改**，钻孔的岩土分层直接用于钻孔进尺的深度分档计价。

### 2.3 标准贯入试验

点「+ 添加」**按地层逐层录入**：自动带出尚未录入标贯的土层与其岩土类别，试验深度档按该层底深度自动匹配，
**每层次数默认为 6 次**（可手工修改）；也可手工改选土层、深度档。
卡片底部自动汇总 **标贯总次数 / 钻孔总数 / 1/3 界限**；
当**标贯总次数不大于钻孔总数的 1/3** 时给出橙色提示「原位测试可能不满足 1/3 总数要求」，
同一提示也会写入计算明细与报告。

### 2.4 圆锥动力触探

选轻型/重型/超重型 → 选土层 → 选深度档（D≤10 / 10<D≤20 / 20<D≤30 / 30<D≤40 / 40<D≤50）→ 填米数。
每个深度档的单价即时显示（例如重型 Ⅲ类 10<D≤20m = 159 元/m）。

| 触探深度 | Ⅰ类 | Ⅱ类 | Ⅲ类 |
|---|---|---|---|
| D≤10 | 34 | 49 | 82 |
| 10<D≤20 | 43 | 62 | 102 |
| 20<D≤30 | 51 | 74 | 122 |
| 30<D≤40 | 61 | 88 | 145 |
| 40<D≤50 | 72 | 105 | 173 |
| 50<D≤60 | 80 | 116 | 193 |

- **选土层 → 岩土类别自动带出**（Ⅰ~Ⅲ类），**触探深度取该层层底自动定档**，界面不再单列深度输入；
- 表格列为：试验土层 / 类别 / 探头 / 孔压 / 米数 / **单价（含深度档）**，单价列直接写成
  `62.00 元/m · 10<D≤20 档`，一眼看出落在哪一档；
- **探头**选单桥 / 双桥（双桥 ×1.15）；勾选「孔压」再加测孔压（×1.2），两者可叠加（×1.38），都已合成进单价；

- 静力触探属**原位测试**，计入「一、岩土工程勘察」分部，随勘察综合系数调整，技术工作费按勘察比例计取。

### 2.6 压水 / 注水试验

表 3.3-4 序号 12，**按段次**计费。卡片右上直接给三个添加按钮：**「+ 压水试验 / + 钻孔注水 / + 探井注水」**，
点哪个就加一条对应记录，行内第一列也能随时改试验项目。

| 试验项目 | 单价（元/段次） |
|---|---|
| 压水试验 D≤20 | 1,753 |
| 压水试验 D>20 | 2,104 |
| 钻孔注水 | 409 |
| 探井注水 | 205 |

- **压水试验**：加完行后选**要做压水的那一层岩土层**，系统按该层**层底深度**自动定档——
  层底 ≤20 m 进 `D≤20`（1,753 元/段次），>20 m 进 `D>20`（2,104 元/段次），
  「试验深度 / 档位」列直接显示 `D>20 · 层底 30 m`；末层为无穷时按 30 m 计并标注「层底∞，按 30 m」；
- **钻孔注水 / 探井注水**：不分层，直接填段次（409 / 205 元/段次）；
- 填段次即出单价与金额，本行即时刷新；卡片底部汇总**压水/注水段次、金额合计**。
- 同样计入「岩土工程勘察」分部、按勘察综合系数调整。

### 2.7 取样

- **取土器默认「锤击法厚壁取土器 φ80~100mm L=150~200mm」（40 / 50 元/件）**，可改为静压法、薄壁、束节式、黄土、
  三重管、探井取土等，单价随取土器类型变化（下拉框内即显示两档单价）。
- 填原状样件数 → 选取样深度（≤30m / >30m）；第二排依次填 **扰动样（15 元/件）、天然抗压岩样 / 饱和抗压岩样（各 25 元/件）、
  点荷载岩样（按「块」计 25 元/块）、胀缩试验样、易溶盐样、取水（40 元/件）**；整卡两排排布，输入框相应收窄。
- **天然抗压岩样联动室内试验「天然单轴抗压」（47 元/组）、饱和抗压岩样联动「饱和单轴抗压」（70 元/组）、
  胀缩试验样联动「胀缩试验」（133 元/件）**；易溶盐样联动「易溶盐分析」。
- 取样卡排在静力触探之前（标准地层 → 钻孔布置 → 标贯 → 动探 → **取样** → 静力触探 → 压水/注水 → 探井/探槽/平硐）。
- 点荷载岩样在人工录入与导入理正两种模式下都有；导入时按备份库的岩样记录带入天然抗压岩样，点荷载块数可另行填写。

### 2.8 探井 / 探槽 / 平硐

按需追加，规格档与岩土类别分别选择，单价即时显示。

### 2.9 附加调整系数与计费

- 附加调整系数（表 3.3-5 + 总则 1.0.9~1.0.10）多选，按总则 1.0.8 合成：
  **综合系数 = 1 + Σ(系数 − 1)**（不能连乘）。例：跟管钻进 1.5 + 夜间 1.2 → 1.5+1.2−2+1 = **1.70**。
- **系数只作用于对应的实物工作**（总则 1.0.8「相应的实物工作收费」）：
  - 「跟管钻进 / 泥浆护壁 / 基岩钻进取芯」「水平孔、斜孔钻探」属**钻探工艺系数**，只放大钻孔（及探井/探槽/平硐）进尺费，
    **不作用于取样、原位测试**——例如只取 1 件水样时，勾选跟管钻进不会把取水费从 40 元变成 60 元；
  - 「夜间作业」「水上作业」「坑道内作业」「线路上作业」「复杂场地」属**作业条件系数**，
    作用于现场实物工作（钻探 + 取样 + 原位测试）；
  - 气温、海拔系数同样只作用于现场实物工作。
- 明细表逐行给出：基价 × 工程量 = 小计，× 相应系数 = 合计。
- 技术工作费 = 技术工作费基数 × 比例（甲 1.20 / 乙 1.00 / 丙 0.80）；
  基数 = 本分部实物费（钻探、探井、取样、原位测试、勘探点定位测量）；室内试验、钻孔波速在各自分部内单独作为基数计取，不并入勘察分部（见 3、4 节）。

### 2.10 导入理正备份库（结算用）

- 入口：切到**「导入理正备份库」模式**后，点右上角「选择理正备份库」（已有数据时显示「重新选择备份库」）。
- 支持：理正备份库 `.mdb / .accdb`（**内置解析，无需安装 Access**）、理正导出的 `.xls / .xlsx / .csv`、
  以及包含上述文件的 `.zip`。
- 备份库直接读取理正内部表：`z_ZuanKong` 钻孔、`z_g_TuCeng` 分层、`z_y_BiaoGuan` 标贯、
  `z_y_DongTan` 动探、`z_c_QuYang` 取土（岩）样、`z_c_ShuiZhi` 水样；工程含多个项目时自动取钻孔最多的那个。
- 读入内容：孔数 / 总进尺 / 分层记录 / 标贯次数 / 动探米数 / 取样件数（原状、扰动、岩样、水样）。
  标贯按「土层 + 类别 + 深度档」汇总次数，动探按 0.1m 锤击记录累加成米数。
- **标准地层严格按备份库里的层号顺序填充**（`TCZCBH` 综合层号 + `TCYCBH` 亚层号），
  **同名层不会被合并**。例如本类工程库中 ①素填土 / ②红黏土 / ③红黏土 / ④石灰岩 / ⑤石灰岩 /
  ⑥充填溶洞 / ⑥1溶洞 共 7 层，界面就按这 7 层排列，层号沿用理正的序号（亚层显示为 ⑥1）；
  该模式下**不显示层底深**（深度一律以各孔实测分层为准）。标贯、动探行的土层按「第几层」精确对应，
  因此 ②红黏土 与 ③红黏土 可以分别选取、分别改类别，不会串层。
- 导入后数据直接填在导入模式的界面里（标准地层、钻孔布置、标贯、动探、取样），顶部显示导入结果与
  「重新导入 / 清除实测数据」按钮；**孔深按备份库实测值只读**，标贯 / 动探 / 取样可直接修改，
  改标准地层名称/类别会自动同步标贯、动探与钻孔分层。计价类别自动切为**结算**。
- 两种模式各自保存一套数据：切回「人工录入」看到的是原来手工录入的那套（层底深、孔型孔深都可编辑），
  再切回来仍是理正实测数据，互不覆盖。点「清除实测数据」只清导入模式的数据。
- **SQL Server 的 `.bak` 备份无法离线解析**：请在理正勘察中「打开工程 → 数据输出 / 导出到 Excel」，
  导出钻孔表、分层表、原位测试表后再导入。

## 七、左栏费用汇总

```
基准价 = 岩土工程勘察（实物 + 技术）+ 室内试验（实物 + 技术）
        + 工程物探（实物 + 技术）+ 其他费用（实物 + 技术）
        + 工程测量（实物 + 技术）
合同价 = 基准价 × (1 − 下浮%)
折合综合单价 = 合同价 ÷ 总进尺（元/m）

五个分部**各自独立统计**：每个分部的实物费、技术费、分部小计都在该模块底部的「分部统计」条里列出，
小计相加即为基准价，不存在「并入某个分部、小计记 0」的情况。
室内试验、钻孔波速、勘探点定位测量与勘察一并完成时，技术费按勘察比例计取（不是 10% / 22%）；
其他费用的技术费只按「勘探点定位测量」的实物费计取，台班、验槽、报告工本费不计技术费。
```

左栏表格实时显示各分部的**实物费 / 技术费 / 小计**（单位：万元），表格上方为**各费用占比饼图**：
环形图按五个分部的小计占比绘制，圆心显示基准价合计，右侧图例列出各分部百分比（悬停显示金额），
零金额的分部不占扇区；表格下方依次给出基准价、下浮 %、**合同价**与**折合综合单价**
（合同价 ÷ 总进尺，鼠标悬停可见计算式），改动即时重算。

「导出 Excel」生成一个工作簿，含三个工作表，可直接接续预算模板：

1. **费用计算书**：序号 / 项目 / 规格 / 单位 / 单价 / 工程量 / 小计 / 附加系数 / 合计，按分部小计与总价；
   金额列是**真正的 Excel 公式**（`小计 = 单价 × 工程量`、`合计 = 小计 × 系数`、`分部实物费 = SUM(…)`、
   `技术费 = 实物费 × 比例`），改单价或工程量后自动重算；
   三张表均设置 **A4 纸张、按页宽缩放一页、水平居中、页边距与页脚页码**，打印区域自动限定到数据末行；
2. **工作量清单**：逐孔 × 岩土类别 × 深度档的进尺矩阵（与预算模板「工作量清单」一致）；
3. **分层明细**：逐孔逐层的层顶、层底、层厚与类别，便于核对；**层号按报告惯用圈码输出**（`①`、`①1`、`⑥1`）。

**技术工作费行的「规格 / 说明」列会写明基数与费率依据**（如「基数＝本分部实物工作费；费率 120%（岩土工程勘察 甲级，第一章 1.0.6 条）」、
「基数＝勘探点定位测量实物工作费；费率 120%（勘察比例）」），打印或转 PDF 后仍能看清比例来源。

五个分部在计算书中各自依次列出「实物工作费（SUM）」「技术工作费（×比例）」「分部小计（=实物+技术）」，
最后用「勘察费基准价（一+二+三+四+五）」把各小计相加；工程物探分部有两档比例时，技术费写成
`=SUM(波速行)×勘察比例 + SUM(其他物探行)×22%`。合同价下方另列**折合综合单价（元/m）**。

「生成报告」生成 Word 报告（.docx），文件名带预算/结算标记，内容依次为：

1. **工程概况**（工程名称、建设单位、勘察单位、等级、钻孔数、进尺、最深孔、计价类别）
2. **计价依据**（计价格〔2002〕10 号、计费公式、系数合成规则、技术工作费比例）
3. **勘察工作量统计**（地层、钻孔、标贯、动探、取样、试验、物探点数）+ **标准地层一览**
   （层号按圈码 ①、①1、⑥1 输出，含岩土名称、类别、层底深度、层厚、分层记录；
   最后一层为无穷时层底列显示「至孔底」）
4. **费用计算明细**（逐条列价，含实物费、技术费、分部小计；**五个分部合并为一张 A4 连续表**，
   分部标题作为表内通栏行；其他费用分部的技术费注明「仅勘探点定位测量计取」，工程测量分部注明 22% 口径）
5. **附加调整系数**说明
6. **费用统计表**（五个分部的实物/技术/小计逐行列示并相加，再列下浮、合同价，附大写金额与折合综合单价）
7. **编制说明**与软件自动提示

另可「保存」为 `.kcsj` 项目文件，下次「打开」继续编辑。

## 九、注意事项

- 单价取自 2002 收费标准原表；若合同另有约定或地方有补充规定，可直接在界面改单价、系数、下浮率。
- 软件按标准条文自动取价，但**岩土类别判定仍需人工确认**（同一土层随稠度、密实度、风化程度不同可能跨类）。
- 标贯 1/3 提示为工程量合理性提醒，不改变取费结果，请按实际情况补充原位测试。
- 理正备份库若是 SQL Server `.bak`，请先导出 Excel 再导入。
