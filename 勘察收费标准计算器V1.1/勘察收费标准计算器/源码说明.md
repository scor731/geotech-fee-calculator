# 源码说明 · 工程勘察收费标准计算器 v1.1 by DK星爷

## 目录结构

```
源码\
├─ app.py                        程序入口（本地 HTTP 服务 + pywebview 窗口 + 打包自检）
├─ core\
│   ├─ version.py                版本号（唯一来源：v1.1 by DK星爷）
│   ├─ standards.py              收费标准表（钻孔、取样、标贯、动探、物探、室内试验、工程测量基价 + 项目族 + 复杂程度判定表）
│   ├─ engine.py                 计价引擎（五个分部各自 实物工作费 + 技术工作费 + 附加调整系数）
│   ├─ label.py                  层号显示格式（界面数字 1/1-1 ⇄ 报告圈码 ①/①1）
│   ├─ lizheng.py                理正备份库解析（.mdb / .accdb / .xls）
│   ├─ exporter.py               导出 Excel 费用计算书
│   ├─ report.py                 生成 Word 预算 / 结算报告
│   └─ rpc.py                    本地 RPC 服务（POST /rpc）
├─ web\                          前端（原生 HTML/CSS/JS，无框架、无联网）
│   ├─ index.html
│   ├─ app.js
│   └─ app.css
├─ 工程勘察收费标准计算器.spec    PyInstaller 打包配置
├─ version_info.txt              exe 文件属性中的版本资源（1.1 / DK星爷）
├─ requirements.txt              运行依赖
├─ icon.ico / icon.png           图标（"费"）。make_icon.py 可重新生成
└─ 使用说明.md                   完整功能说明（在上一级目录）
```

## 直接运行（不打包）

```bat
pip install -r requirements.txt
python app.py
```

需要 Windows 自带的 Edge WebView2 运行时（Win10 1803+ / Win11 默认已装）。

## 重新打包 exe

```bat
pip install pyinstaller==6.22.3
pyinstaller --noconfirm 工程勘察收费标准计算器.spec
```

产物：`dist\工程勘察收费标准计算器.exe`，单文件、免安装，约 24 MB。

## 版本号维护

- 界面标题、左上角副标题、底栏、帮助对话框、Word 报告封面、Excel 计算书，全部取自 `core\version.py`；
- 改版本时同时修改 `version_info.txt` 的 `FileVersion` / `ProductVersion`（Windows 文件属性里显示的值），
  以及 `web\index.html` 里静态占位的标题/副标题/底栏文字（启动后会被 version.py 覆盖，但离线打开时先显示静态值）；
- 修改后重新执行一次 PyInstaller 即可。

## 自检（可选）

```bat
set KCSJ_SELFTEST=D:\temp\kcsj
工程勘察收费标准计算器.exe
```

会在指定目录生成 `selftest.log`（标准表数量、Excel/Word 导出、计价结果）并输出 `selftest.xlsx`、`selftest.docx`。
加 `set KCSJ_SELFTEST_MDB=<理正备份库路径>` 可一并验证理正库解析。

## 体积优化（v1.1 起）

exe 从约 24.5 MB 压到约 16.6 MB，四个手段（都已写进 spec，重新打包自动生效）：

1. **excludes**：剔除运行期用不到的包（tkinter / unittest / pydoc_data / PIL / sqlite3 / pefile /
   PyInstaller 自身 / xmlrpc / ftp・smtp 客户端库等）；注意**不能 exclude distutils / setuptools /
   pip / wheel**——PyInstaller 内部会用 alias_module 指向它们，exclude 后构建直接报 ValueError；
   也**不能 exclude `pdb`**——`construct`（理正 Access 备份库解析依赖）在 `construct/debug.py`
   顶层 import pdb，排除后 `construct` / `access_parser` 导入失败，exe 读不了 `.mdb`
   （源码直接运行不受影响，只有打包后才暴露，v1.1 曾因此出现「读入理正备份库」失效）；
2. **optimize=2**：编译字节码时去掉文档字符串与 assert；
3. **只保留 win-x64 的 WebView2 运行时**（webview 的 collect_all 默认把 arm64 / x86 的
   WebView2Loader.dll 也打进来，spec 里的 `_drop_foreign_runtimes` 会剔除）；
4. **UPX 压缩**：构建前把 `upx.exe` 所在目录加入 PATH 即可（spec 里 `upx=True`），
   例如 `set PATH=C:/tools/upx-4.2.4-win64;%PATH%` 后再跑 PyInstaller；没有 UPX 时也能打包，
   只是体积回到约 19 MB。

UPX 下载：https://github.com/upx/upx/releases （win64 版解压即可，无需安装）。
