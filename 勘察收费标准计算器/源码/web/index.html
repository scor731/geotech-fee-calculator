使用说明 · 计费要点

① 录入顺序

「工程勘察」模块 →「人工录入」：先填标准地层（主层编号 + 亚层编号均为数字，如 1、1-1，与理正口径一致； 岩土名称点一下输入框就列出全部标准名称（带 Ⅰ/Ⅱ/Ⅲ 类别标签，点击填入并自动带出类别），也可自行输入；类别也可手工改）， 再设钻孔总数并按一半分配控制孔，然后填标贯、动探、取样、静力触探、压水 / 注水；结算项目可点「导入理正备份库」按钮， 读入理正备份库（适用8.5版本），实测数据会直接填入下方标准地层、钻孔、标贯、动探与取样，可继续修改。

标准地层最后一层的层底深留空即可——按「无穷」处理，自动延伸至孔底，不用逐层填写；如需限定末层层底，直接填数字。

导出的 Word / Excel 中，层号自动按报告惯例显示为圈码：1 → ①，1-1 → ①1，6-1 → ⑥1。

② 取费公式（总则 1.0.4）
勘察收费 = 基准价 × (1 ± 浮动幅度)　（本软件以下浮幅度体现） 基准价 = 实物工作收费 + 技术工作收费 实物工作收费 = 收费基价 × 实物工作量 × 附加调整系数 技术工作收费 = 实物工作收费 × 技术工作费比例
③ 附加调整系数不连乘（总则 1.0.8）

两个以上系数相加、减去系数个数、再加 1。例：跟管钻进 1.5 + 夜间 1.2 → 1.5+1.2−2+1 = 1.70。

④ 技术工作费比例

岩土工程勘察：甲级 120%、乙级 100%、丙级 80%；工程物探 22%；室内试验 10%；工程测量 22%。

注意计费口径：室内试验、钻孔波速、勘探点定位测量通常与勘察一并完成，其技术费按勘察比例计取， 但仍分别在各自分部内统计并计入基准价——基准价 = 岩土工程勘察 + 室内试验 + 工程物探 + 其他费用 + 工程测量，五部相加，不并入勘察分部。 只有独立委托、单独提交成篇报告时，才分别按 10%、22%、22% 单独计取（卡片右上角可切换）。

勘探点定位测量（原「定点测量」）放在「其他费用」模块同一张卡片内单独统计，按 1000 元/组日计列（单价按标准固定，界面不可改，只填组日数）；卡片内直接显示比例系数（技术工作费比例：默认勘察比例 甲级 ×1.20 / 乙级 ×1.00，可切换为工程测量 22%），同属勘察实物工作。台班、验槽、报告费按基价直接计列、不计技术费。

钻孔波速测试用「人工录入」方式时，按表格式录入一行：测试孔数 | 每孔测试深度 | 深度档 | 测试方法 | 单价 | 金额。 每孔测试深度默认取本项目最深孔（自动填在格子里），如实际测试深度不同可直接改，深度档按填写的每孔测试深度判定 （不按最深孔），改孔数或深度即时出单价与金额 （金额 = 单价 × 孔数 × 每孔深度 × 物探附加系数，下方注明「几孔 × 几 m = 几 m」；不足 2 个组日自动按 2000 元计）； 导入理正备份库时则按各孔实测孔深分档汇总。

标贯 / 动探选了试验土层后，深度档按该层层底深度自动匹配（末层为无穷时按最深孔），档位下拉仍可手工改。

原位测试里除标准贯入、动力触探外，另列静力触探与压水 / 注水试验，均计入「一、岩土工程勘察」分部、随勘察综合系数调整：

· 静力触探（表3.3-4 序号3）：选土层 → 类别自动带出，触探深度取该层层底自动定档，界面只填米数； 单价列直接显示「62.00 元/m（10<D≤20 档）」，双桥探头 ×1.15、加测孔压 ×1.2 也在单价里合成。

· 压水 / 注水试验（表3.3-4 序号12）：右上三个按钮「+ 压水试验 / + 钻孔注水 / + 探井注水」按需添加； 压水试验再选做压水的那一层岩土层，按层底深度自动定 D≤20（1753）/ D>20（2104） 档并显示在「试验深度 / 档位」列； 注水按钻孔 409、探井 205 元/段次，填段次即出金额。

各模块底部都有分部统计：实物工作费 / 技术工作费 / 分部小计 / 技术费比例 / 计入基准价，口径与左栏汇总、占比饼图、Word 费用统计表、Excel 计算书完全一致。

⑤ 室内试验：取样一填数就自动带出

在「工程勘察 · 取样」填入件数后，常用试验（常规土工样 / 颗粒分析 / 天然单轴抗压 / 饱和单轴抗压 / 点荷载强度 / 胀缩试验 / 易溶盐分析 / 水质简分析）会自动出现在「室内试验项目」表中并按取样数量联动， 不需要再点快捷添加；删除后不会反复加回。取样卡里：天然抗压岩样→天然单轴抗压（47 元/组）、 饱和抗压岩样→饱和单轴抗压（70 元/组）、胀缩试验样→胀缩试验（133 元/件）。 需要逐项列示时用「快捷添加 · 常规分项」：含水率 8、密度 8、比重 19、液限 15、塑限 30、压缩 40、直剪 49， 7 项合计 169 元/件，正好等于常规土工样。

⑥ 工程测量模块（第二章）

工程测量按类别分成五个横向标签：地面测量、水域测量、地下管线测量、洞室测量、其他测量， 标签上显示该类已填金额，点一下切换，不必在长页面里翻找。每类按收费标准原表样式逐行列出： 项目由软件给出，第二列选等级 / 比例尺（二等、三等…、1:500…、C/D/E 级），再填工程量， 单价按「所选档次 + 当前复杂程度」自动取，金额 = 单价 × 工程量 × 系数，每组底部有本组合计。

复杂程度的判定标准放在右栏「收费标准对照」里：右栏页签与中栏五个标签一一对应， 每个页签先列复杂程度判定表（地面 表2.2-1、水域 表2.3-1、管线 表2.4-1、洞室 表2.5-1），再列收费基价表， 当前选中的档位会高亮。按判定表得出结论后，在中栏五个类别标签右侧（同一行）选定「简单 / 中等 / 复杂」， 未定档时右端提示「请选择复杂程度」；单价立即按该档重取。若已填了工程量却还没定档， 右端提示转为橙色，表格上方同时出现黄色提醒，定档后自动消失。

· 地面测量（表2.2-2）：控制测量（三角(边)、导线、水准、GPS，按点 / km；图根点并入「导线」的等级选项， 选它时计费单位自动由 km 变为点）、 地形测量（按 km²，1:200~1:10000）、断面测量 / 架空索道（按 km）。
· 水域测量（表2.3-2）：湖江河塘沼泽地按 km²、河道断面按 km；滨海区已按表注单列为一行（×1.5）。
· 地下管线测量（表2.4-2）：地下电缆、工业管道、上下水及暖气管道，按 km。
· 洞室测量（表2.5-2）：按洞室长度 km 计。
· 其他测量（表2.6-1）：地形图数字化（标准图幅）、缩放图（100cm²）、近景摄影、小型工程测量、定点测量（组日）； 小型工程测量不足 3 个组日按 3 个组日计。

建筑群区、滨海区已按表注单列为一行（地形测量建筑群区 1:200×1.8、其余×2.0；水域滨海区×1.5； 数字化建筑群区×2.0、缩放图建筑群区×1.5），选行即可，不用再勾系数。 附加调整系数按《使用手册》对表2.2-3 的解释逐条匹配计算：序号1~2→三角(边)、3→房顶标志(三角)/墙上水准(水准)、 4→导线测量、5→GPS、6~7→导线、8~14→地形测量；总则气温 / 海拔系数作用于全部项目。 同一项目上叠加多个系数时按总则 1.0.8「相加−个数+1」合成、不连乘；卡片右上角只显示当前确实生效的项目及其倍数， 每条系数下方也注明「作用于××测量」。表2.2-3 只适用于地面测量——水域 / 管线 / 洞室 / 其他测量 在标准里没有专项附加系数，这四个标签下只显示总则系数（气温、海拔）。 技术工作费统一 22%，本分部独立统计、独立计入基准价。

⑦ 钻孔计价规则

按岩土类别（Ⅰ~Ⅵ）与深度档（每 10m 一档，60~100m 两档）分别取价；同一层跨深度档时自动拆分。 深度 >100m 每增 20m 按前一档 ×1.2。

⑧ 导出与报告

「导出 Excel」生成费用计算书、工作量清单、分层明细三张表；「生成报告」输出 Word 版预算/结算报告 （工程概况、计价依据、工作量统计、费用计算明细（各分部合并为一张 A4 连续表）、费用统计表）； 「保存」生成 .kcsj 项目文件可再次打开。

左栏「合同价」下方显示折合综合单价 = 合同价 ÷ 总进尺（元/m），Word / Excel 中同步列示。
