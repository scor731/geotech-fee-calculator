# 源码说明 · 工程勘察收费标准计算器 v1.0 by DK星爷

## 目录结构

```
源码\
├─ app.py                        程序入口（本地 HTTP 服务 + pywebview 窗口 + 打包自检）
├─ core\
│   ├─ version.py                版本号（唯一来源：v1.0 by DK星爷）
│   ├─ standards.py              收费标准表（钻孔、取样、标贯、动探、物探、室内试验）
│   ├─ engine.py                 计价引擎（实物工作费 + 技术工作费 + 附加调整系数）
│   ├─ lizheng.py                理正备份库解析（.mdb / .accdb / .xls）
│   ├─ exporter.py               导出 Excel 费用计算书
│   ├─ report.py                 生成 Word 预算 / 结算报告
│   └─ rpc.py                    本地 RPC 服务（POST /rpc）
├─ web\                          前端（原生 HTML/CSS/JS，无框架、无联网）
│   ├─ index.html
│   ├─ app.js
│   └─ app.css
├─ 工程勘察收费标准计算器.spec    PyInstaller 打包配置
├─ version_info.txt              exe 文件属性中的版本资源（1.0 / DK星爷）
├─ requirements.txt              运行依赖
├─ icon.ico / icon.png           图标（"费"）。make_icon.py 可重新生成
└─ 使用说明.md                   完整功能说明（在上一级目录）
```

## 直接运行（不打包）

```bat
pip install -r requirements.txt
python app.py
```

需要 Windows 自带的 Edge WebView2 运行时（Win10 1803+ / Win11 默认已装）。

## 重新打包 exe

```bat
pip install pyinstaller==6.22.3
pyinstaller --noconfirm 工程勘察收费标准计算器.spec
```

产物：`dist\工程勘察收费标准计算器.exe`，单文件、免安装，约 24 MB。

## 版本号维护

- 界面标题、左上角副标题、底栏、帮助对话框、Word 报告封面、Excel 计算书，全部取自 `core\version.py`；
- 改版本时同时修改 `version_info.txt` 的 `FileVersion` / `ProductVersion`（Windows 文件属性里显示的值）；
- 修改后重新执行一次 PyInstaller 即可。

## 自检（可选）

```bat
set KCSJ_SELFTEST=D:\temp\kcsj
工程勘察收费标准计算器.exe
```

会在指定目录生成 `selftest.log`（标准表数量、Excel/Word 导出、计价结果）并输出 `selftest.xlsx`、`selftest.docx`。
加 `set KCSJ_SELFTEST_MDB=<理正备份库路径>` 可一并验证理正库解析。
